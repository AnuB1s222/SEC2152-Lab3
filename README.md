# Репозиторий документации СМИБ

## Назначение
Репозиторий предназначен для хранения и контроля версий документов системы менеджмента информационной безопасности учебной организации.

## Структура
- 01-politika — политика ИБ верхнего уровня.
- 02-chastnye-politiki — частные политики.
- 03-procedury — процедуры и регламенты.
- 04-instrukcii — инструкции и чек-листы.
- 05-zapisi — шаблоны записей.

## Порядок изменения документов
1. Создать отдельную ветку.
2. Внести изменения в документ.
3. Зафиксировать изменения коммитом.
4. Создать Pull Request.
5. Получить замечания и одобрение рецензента.
6. Выполнить слияние после утверждения.
7. Присвоить утверждённой версии тег.

## Контроль изменений
История Git позволяет установить автора, дату и содержание каждого изменения. Основная ветка main должна быть защищена от прямой записи.
